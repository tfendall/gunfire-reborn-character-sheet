0.13.31 authoritative damage display

The damage header and source percentages use the latest received server total.
Source/element breakdown is snapshotted when reports drain; it does not keep
advancing against a stale server denominator between reports. A positive remainder
is Unattributed damage with Unknown element. A negative remainder is explicitly
Reconciliation adjustment; raw hits are never rescaled or silently deleted.
Raw capture ledger and diagnostic gap analysis are unchanged. Until first report,
the UI falls back to captured damage. Manual Reset clears capture and anchors the
server/source offsets to the NEXT report, excluding hits during that short wait.
Sampling remains once per second when ready; loading/UI cooldowns can delay it.

The main-thread scoreboard drain requires the local player's S8 inventory to contain
item 1007, a complete copied breakdown, nonnegative values, unique detail keys,
and category 1 sum equal to the reported seasonal total. It then replaces the
captured seasonal partition with server detail values: detail 11 is POLE MONARCH
Orb, other detail IDs retain generic seasonal labels. Replacing the whole seasonal
partition avoids inventing a per-orb packet mapping (208/353 are not exclusive).
Server details have no element, so they use Unknown. The overall authoritative
total and raw damage/audit ledger remain unchanged. Invalid or incomplete reports
fall back to captured attribution. Reset baselines include seasonal detail values;
if that baseline was unavailable, seasonal replacement is disabled for the reset
window rather than crediting pre-reset damage. No new native hooks are installed.
